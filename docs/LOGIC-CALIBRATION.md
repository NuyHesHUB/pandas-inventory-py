# FIFO 로직 교정 기록 (Logic Calibration)

도구가 만든 결과물과 **사람이 직접 만든 실제 결과물**을 대조해서, 미세하게 어긋나는
품목을 찾아 로직을 지속적으로 교정하기 위한 문서다.

운영 방식: 사람이 결과물을 만들 때마다 도구 출력과 비교 → 어긋난 품목을 아래
"사례 기록"에 남김 → 원인을 분류 → 수정 시 **반드시 회귀 테스트를 함께 추가** →
수정 이력에 기록.

## 현재 로직 요약

기간 판매량과 cutoff 시점 종료재고를 더해 최근 입고부터 역산(scope)한 뒤,
그 범위의 가장 오래된 lot부터 판매량을 FIFO 배분한다 (`fifo_for_product`).

### 입고 제외 휴리스틱 (원화/국내/반품 제외)

| 조건 | 판정 | 위치 |
|---|---|---|
조건은 **두 가지**다. 공급처 상호로 판정하지 않는다.

| 조건 | 판정 | 위치 |
|---|---|---|
| 공급처/매출처/비고에 "반품"·"return" 포함 | 제외 | `__is_return__` |
| 단가 ≥ 500, 또는 단가·공급처 셀 서식이 ₩/원/KRW | 원화(국내 매입)로 간주, 제외 | `__is_high_krw_unit_price__` (← `__is_krw_accounting_format__` 포함) |

**국내 매입은 입고(수입)단가 열의 ₩500 이상으로만 판별한다.** 2026년 시트 전수
조사에서 단가 셀 서식과 값이 정확히 갈린다.

| 단가 셀 서식 | < 500 | ≥ 500 |
|---|---|---|
| `"₩"#,##0` | 0 | 235 |
| `\$#,##0.00` 계열 | 336 | 0 |
| `[$¥-804]#,##0.00` 계열(엔화) | 33 | 0 |

₩ 서식인 행은 전부 500 이상이고 500 이상인 행은 전부 ₩ 서식이다. 달러·엔화 행은
하나도 500을 넘지 않으므로 이 임계값에서 외화가 오발될 여지가 없다.

2026-10-27 이전에는 **공급처 상호에 한글이 있으면 국내 매입**으로 보는 조건이
하나 더 있었는데, "화동"·"Hefei Top Industry(무역회사)" 같은 한글 상호 수입처의
입고를 통째로 떨어뜨려 폐기했다 (아래 수정 이력 참조).

⚠️ 남은 오발 여지: "반품 아님" 같은 메모, 복사-붙여넣기로 묻거나 빠진 ₩ 서식.
오발 사례가 나오면 여기 기록할 것.

### 날짜 3원화 — 행마다 세 가지 날짜가 다른 용도로 쓰인다

| 용도 | 기준 |
|---|---|
| 판매 집계 | 날짜 우선, 없으면 도착일 (`__event_date__`) |
| 입고 lot | **도착일 우선**, 없으면 날짜 (`__in_date__`) |
| 재고 스냅샷 | 날짜만 (`__row_date__`) |

## 남은 용의자 (미확정 — 사례가 나오면 대조할 것)

1. **경계일 날짜 불일치**: 운송 중 입고(날짜 ≤ cutoff < 도착일)는 lot에서 빠지는데
   현재고에는 반영돼 있으면 부족분이 생겨 보정 seed가 발동 → 오래된 단가가 끼어듦.
   *시그니처: 월말/월초 경계에 입고가 걸친 품목에서 뜬금없는 옛 입고일 lot.*
2. **제외 휴리스틱 오발**: 위 표의 2개 조건 참조.
   *시그니처: 특정 입고 건 하나가 배분에서 통째로 빠짐.*
7. **단가 빈칸 국내 매입**: 단가가 비어 있으면 ₩500 규칙이 걸 수 없다. ₩ 서식이
   남아 있으면 걸리지만 서식이 어긋난 행은 lot으로 들어가 단가·환율 빈 행을 만든다.
   *시그니처: 결과물에 단가/환율/금액이 모두 빈 행.* (사례 기록 참조, 규칙 미정)
3. **보정 seed의 은폐**: 역산 범위가 lot 합계로 안 채워지면 부족분을 가장 오래된
   유가 lot에 붙인다. 합계는 항상 맞으므로 다른 원인을 가린다.
   *시그니처: 가장 오래된 입고일에 비정상적으로 큰 배분량.*
4. **품명 표기 변형**: 소스 내 "TT(CP)" vs "TT (CP)" 같은 변형은 서로 다른 품목으로
   집계됨 (템플릿↔소스 매핑만 canon 비교, 소스끼리는 미통합).
   *시그니처: 판매량 자체가 눈에 띄게 부족.*
5. **연도 경계**: 전년 12월 이력이 새해 시트에 "12월 30일"로 적히면 당해 12월로
   파싱됨. *시그니처: 연초 기간에서 기초재고성 lot 누락.*

## 불일치 리포트 절차

어긋난 품목을 발견하면 아래 순서로 확인하고 사례 기록에 남긴다.

1. **기본 정보**: 품목명, 대상 기간, 도구 출력 lot(입고일/단가/환율/수량) vs
   사람 결과물 lot.
2. **원장에서 확인할 것** (위 용의자와 대응):
   - [ ] cutoff 직전 행의 現재고 칸이 비어 있거나 텍스트인가?
   - [ ] 같은 날짜에 입고/거래 행이 여러 건인가?
   - [ ] 어긋난 lot 행의 날짜와 도착일이 cutoff를 사이에 두고 갈리는가?
   - [ ] 단가가 ≥ 500(₩)이거나, 단가 칸이 비었거나, 비고에 "반품" 문자열이 있는가?
   - [ ] 원장에 같은 품목의 표기 변형(공백 차이 등)이 있는가?
3. **분류 후 수정**: 원인이 특정되면 수정하고, 해당 사례를 재현하는 단위 테스트를
   `tests/`에 추가한 뒤 위 "수정 이력" 표를 갱신한다.
